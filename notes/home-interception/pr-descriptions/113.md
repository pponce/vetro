A single Home press can reach the launcher through both the physical input listener and the focused window. The second delivery can immediately hide the overlay that the first delivery opened.

This gives both handlers one debounce state, preserves the 1.5-second window used to suppress delayed firmware echoes, and ignores window copies while the overlay is hidden. A later physical press can still toggle the overlay normally.

This addresses duplicate handling of one press. It does not intercept Home before Samsung receives it or prevent Samsung Home from briefly appearing. Direct physical Home delivery is the separate work discussed in #30.

The current branch is based directly on the 0.5.0-based upstream baseline `180d9845`; it does not include the other Home feature PRs.
