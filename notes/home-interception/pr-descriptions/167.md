This adds optional double-press Home in Vetro overlay mode. The first press immediately shows or hides the overlay; a distinct second press within 350 ms opens either the Home tile's destination or a separately selected app.

The gesture uses physical event timestamps and requires a down/up/down sequence from the same input source. Repeats and duplicate events cannot complete a double press. Navigation and input reconnects cancel unfinished gestures. The feature is off by default and inactive in Custom launcher mode.

This is a stacked draft. The branch includes the prerequisite Home event, close-guard, tile and assignment work represented by #113, #117, #118 and #119. Please review the final feature commit separately and rebase after the prerequisites are settled. #169's Samsung Home launch correction is separate and is not included in this branch.

The current branch receives Home through the native listener. It does not itself prevent Samsung Home from appearing first. Integration with #30's direct interception needs to preserve the press/release timing; replacing each Home press with a plain FIFO toggle would bypass this gesture handler.
